Codon-level variant annotation

A VCF lists bases.
get_MNV reads codons.

Two substitutions in one codon make one amino acid, not two. get_MNV translates every codon whole, places each indel against its gene and, given a BAM or CRAM, counts the reads that carry the changes together.

Try it: one codon, two readings

Change any base. Each change is read on its own, the way a base-by-base annotator reads it, and then all together, the way get_MNV reads the codon.

The script that makes this interactive did not run. Here is the first example, worked out.

One base at a time this codon gives Cys and Pro. Read whole, it gives Ser, which neither of them names.

Translated with the bacterial code (table 11), get_MNV's default; nine NCBI tables are supported. This is a codon inside a gene: the first codon of a gene is read as an initiator instead.

2

What it does with a VCF

Steps 1 to 3 need no reads. A BAM or CRAM only adds step 4, which turns "these two changes are in one codon" into "these two changes are on one molecule".

  1. 1

    Decompose

    Each record's REF and ALT into the changes it holds: SNVs, MNVs, insertions, deletions, delins.

  2. 2

    Place

    Each change in its gene and codon, from a GFF or a gene table, on either strand and across exons.

  3. 3

    Translate

    The whole codon, in one of nine NCBI genetic codes, and each indel against the protein.

  4. 4

    Count

    With reads: how many carry each change, on which strand, and whether the changes travel together.

  5. 5

    Write

    A TSV, a VCF with ANN, BCF on request, and a report that opens offline.

Install

One binary, no C dependencies, on macOS, Linux and Windows. A desktop app does the same with drag and drop.

Bioconda

conda install -c bioconda get_mnv

From source

git clone https://github.com/PathoGenOmics-Lab/get_MNV.git
cd get_MNV
cargo install --path .

Rust 1.89 or newer.

Desktop app

macOS, Linux and Windows builds on the Releases page, with a guided tutorial.

Not signed with an Apple certificate: on the first launch, right-click the app and choose Open.

Check what you downloaded

Every release carries a SHA256SUMS file covering all of its assets. Download it next to the file you want and check them together; each file it finds prints OK.

sha256sum --ignore-missing -c SHA256SUMS

On macOS, shasum -a 256 --ignore-missing -c SHA256SUMS does the same.

Your first run

The repository ships a M. tuberculosis sample: a VCF, its reference and a gene table. From a clone:

get_mnv \
  --vcf example/G35894.var.snp.vcf \
  --fasta example/MTB_ancestor.fas \
  --genes example/anot_genes.txt \
  --both --output-dir out \
  --report report.html
  • 950 records in, 941 rows out: 797 SNP, 10 SNP/MNV codons and 134 intergenic
  • out/G35894.var.snp.MNV.tsv and out/G35894.var.snp.MNV.vcf
  • report.html, the example report
