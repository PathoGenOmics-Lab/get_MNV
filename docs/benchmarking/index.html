How it works

Benchmarking

get_MNV includes a built-in benchmark binary for measuring variant annotation performance.

Synthetic benchmark#

cargo run --release --bin bench_variants -- --warmup 5 --iters 30

Scale up the synthetic dataset:

cargo run --release --bin bench_variants -- \
  --warmup 3 --iters 20 --threads 4 --synthetic-scale 4

Dataset benchmark#

Run against a real dataset with CSV export:

cargo run --release --bin bench_variants -- \
  --dataset example \
  --warmup 5 --iters 20 \
  --threads 4 \
  --csv benchmark.csv \
  --max-avg-ms 200

This appends one row per run to benchmark.csv.

Benchmark options#

ArgumentDefaultDescription
--warmup <N>5Warmup iterations (not measured)
--iters <N>30Measured iterations
--threads <N>1Worker threads
--dataset <DIR>nonePath to dataset directory (FASTA + VCF + annotation)
--contig <NAME>allRestrict to a single contig
--csv <FILE>noneAppend CSV results
--max-avg-ms <MS>noneFail if average exceeds threshold (regression detection)
--synthetic-scale <N>1Scale factor for synthetic gene/SNP count
