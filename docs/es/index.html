Anotación de variantes a nivel de codón

Un VCF enumera bases.
get_MNV lee codones.

Dos sustituciones en un mismo codón dan un aminoácido, no dos. get_MNV traduce cada codón entero, sitúa cada indel en su gen y, con un BAM o un CRAM, cuenta las lecturas que llevan los cambios juntos.

Pruébalo: un codón, dos lecturas

Cambia cualquier base. Cada cambio se lee por separado, como lo lee un anotador base a base, y luego todos juntos, como lee el codón get_MNV.

El script que lo hace interactivo no se ha ejecutado. Aquí está el primer ejemplo, resuelto.

Traducido con el código bacteriano (tabla 11), el que usa get_MNV por defecto; admite nueve tablas del NCBI. Es un codón dentro de un gen: el primer codón de un gen se lee, en cambio, como iniciador.

2

Qué hace con un VCF

Los pasos 1 a 3 no necesitan lecturas. Un BAM o un CRAM solo añade el paso 4, que convierte "estos dos cambios están en un codón" en "estos dos cambios están en una molécula".

  1. 1

    Descomponer

    El REF y el ALT de cada registro en los cambios que contienen: SNV, MNV, inserciones, deleciones, delins.

  2. 2

    Situar

    Cada cambio en su gen y su codón, desde un GFF o una tabla de genes, en cualquier hebra y entre exones.

  3. 3

    Traducir

    El codón entero, con uno de nueve códigos genéticos del NCBI, y cada indel contra la proteína.

  4. 4

    Contar

    Con lecturas: cuántas llevan cada cambio, en qué hebra, y si los cambios viajan juntos.

  5. 5

    Escribir

    Un TSV, un VCF con ANN, BCF si se pide y un informe que se abre sin conexión.

Instalación

Un solo binario, sin dependencias de C, en macOS, Linux y Windows. Una aplicación de escritorio hace lo mismo arrastrando y soltando.

Bioconda

conda install -c bioconda get_mnv

Desde el código fuente

git clone https://github.com/PathoGenOmics-Lab/get_MNV.git
cd get_MNV
cargo install --path .

Rust 1.89 o posterior.

Aplicación de escritorio

Versiones para macOS, Linux y Windows en la página de versiones, con un tutorial guiado.

No está firmada con un certificado de Apple: la primera vez, clic derecho sobre la aplicación y Abrir.

Comprueba lo que has descargado

Cada versión trae un fichero SHA256SUMS que cubre todos sus ficheros. Descárgalo junto al que quieras y compruébalos juntos; cada fichero que encuentra imprime OK.

sha256sum --ignore-missing -c SHA256SUMS

En macOS, shasum -a 256 --ignore-missing -c SHA256SUMS hace lo mismo.

Tu primera ejecución

El repositorio trae una muestra de M. tuberculosis: un VCF, su referencia y una tabla de genes. Desde un clon:

get_mnv \
  --vcf example/G35894.var.snp.vcf \
  --fasta example/MTB_ancestor.fas \
  --genes example/anot_genes.txt \
  --both --output-dir out \
  --report report.html
  • Entran 950 registros y salen 941 filas: 797 SNP, 10 codones SNP/MNV y 134 intergénicas
  • out/G35894.var.snp.MNV.tsv y out/G35894.var.snp.MNV.vcf
  • report.html, el informe de ejemplo
